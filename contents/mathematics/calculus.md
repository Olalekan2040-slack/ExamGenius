TOPIC: DifferentiationIntroductionDifferentiation is the process of finding the rate of change (or slope) of a function at any point. It is a core part of calculus and is used to solve real-life problems involving velocity, acceleration, growth rates, optimization (maximum/minimum values), and tangents to curves.For a complete beginner:
Imagine you have a graph of distance against time (a curve). Differentiation tells you the instantaneous speed (gradient/slope) at any exact moment.
The result of differentiation is called the derivative or gradient function.This topic is very important in JAMB Mathematics – usually 4–7 questions every year.
JAMB focuses on:Understanding the concept of limit as the foundation of differentiation
Basic rules of differentiation for algebraic functions (polynomials, fractions, roots)
Differentiation of simple trigonometric functions (sin x, cos x, tan x)

World-standard learning objectives (aligned with Cambridge IGCSE, WAEC, NECO, IB MYP, and A-Level foundation):
Candidates should be able to:Understand and evaluate limits of functions (algebraic and simple trigonometric) as x approaches a value
Apply the basic rules of differentiation: power rule, constant multiple rule, sum/difference rule
Differentiate explicit algebraic functions (polynomials, rational, roots) and simple trigonometric functions (sin x, cos x, tan x)
Find the gradient (slope) of a curve at a given point
Interpret the derivative as the instantaneous rate of change and the slope of the tangent to the curve
Solve simple problems involving differentiation (e.g., finding maximum/minimum, velocity, acceleration)

Factorize and cancel common factors (for 0/0 indeterminate form)  
Rationalize for square roots (multiply by conjugate)  
For trigonometric limits: lim (sin x)/x = 1 as x → 0 (in radians)

Example Question Pattern (simple to hard – JAMB style):Simple: Find lim (x→3) (2x + 5)
Answer: Direct substitution → 2(3) + 5 = 11
Medium: Find lim (x→2) (x² – 4)/(x – 2)
Answer: Factorize → (x–2)(x+2)/(x–2) = x + 2 (x ≠ 2) → limit = 4
Hard: Find lim (x→0) (sin 3x)/x
Answer: Rewrite as 3 × (sin 3x)/(3x) → 3 × 1 = 3 (using lim sin θ/θ = 1)
Advanced (JAMB indeterminate form): Find lim (x→1) (x³ – 1)/(x – 1)
Answer: Factorize → (x–1)(x² + x + 1)/(x–1) = x² + x + 1 → limit = 3

Common Mistakes:Substituting directly when 0/0 occurs (indeterminate)  
Forgetting to use radians for trigonometric limits

SUBTOPIC: Differentiation of Explicit Algebraic and Simple Trigonometrical FunctionsObjective 2: Differentiate explicit algebraic and simple trigonometrical functionsExplanation (basic differentiation rules – memorize these!):Power Rule (most important):
If y = xⁿ → dy/dx = n x^(n–1)Constant Multiple Rule:
d/dx [k f(x)] = k d/dx [f(x)]Sum/Difference Rule:
d/dx [f(x) ± g(x)] = f'(x) ± g'(x)Trigonometric Derivatives (JAMB only tests these):d/dx (sin x) = cos x  
d/dx (cos x) = –sin x  
d/dx (tan x) = sec² x = 1/cos² x

Key Points:Constant → derivative = 0  
For roots: Rewrite as power (e.g., √x = x^(1/2) → derivative = (1/2)x^(–1/2))

Visual Type: differentiation rule summary chart
Visual Items:  Power rule table with examples  
Sine and cosine derivative graphs side by side

Example Question Pattern (simple to hard – JAMB style):Simple: Differentiate y = 5x³ – 2x² + 7x – 4
Answer: dy/dx = 15x² – 4x + 7
Medium: Find the derivative of y = 3x⁴ + 2√x – 5
Answer: Rewrite √x = x^(1/2)
dy/dx = 12x³ + 2 × (1/2)x^(–1/2) = 12x³ + x^(–1/2)
Hard: Differentiate y = sin x + cos x + tan x
Answer: dy/dx = cos x – sin x + sec² x
Advanced (JAMB application): Given y = x³ – 6x² + 9x – 2, find dy/dx and the gradient at x = 2.
Answer: dy/dx = 3x² – 12x + 9
At x = 2: 3(4) – 12(2) + 9 = 12 – 24 + 9 = –3

Common Mistakes:Forgetting to multiply by the power when using power rule  
Wrong sign for derivative of cos x (–sin x)  
Treating constants as variables

Final High-Level Tips for JAMB Success:Memorize the power rule and trig derivatives – write them daily  
Practice differentiating polynomials and simple trig functions separately  
Always simplify before differentiating (e.g., rewrite roots as powers)  
For limits: factorize or use standard trig limits
