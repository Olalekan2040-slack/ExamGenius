TOPIC: SetsIntroductionSets are one of the most fundamental concepts in mathematics. A set is simply a well-defined collection of distinct objects (called elements or members).  For a complete beginner:
Think of a set as a bag or group containing different items, where:Order does not matter  
No item is repeated  
We only care about whether something is inside or not

Examples of everyday sets:  The set of vowels in English = {a, e, i, o, u}  
The set of days in a week = {Monday, Tuesday, Wednesday, Thursday, Friday, Saturday, Sunday}  
The set of even numbers less than 10 = {2, 4, 6, 8}

Example: The set of months with 32 days = ∅
Singleton set → has exactly one element
Example: {7} or {Monday}
Finite set → has a limited number of elements
Example: {1, 2, 3, 4, 5}
Infinite set → goes on forever
Example: Set of natural numbers ℕ = {1, 2, 3, …}
Universal set (U) → the set that contains all elements under consideration
Example: In a class, U = all students in the class
Subset (⊆) → every element of A is also in B
Example: If A = {1, 2}, B = {1, 2, 3}, then A ⊆ B
Proper subset (⊂) → A ⊆ B but A ≠ B
Example: {1, 2} ⊂ {1, 2, 3}
Equal sets → have exactly the same elements
Example: {a, e, i} = {i, a, e}
Disjoint sets → have no element in common
Example: A = {1, 3, 5}, B = {2, 4, 6} → A ∩ B = ∅
Complement (A′ or Aᶜ) → all elements in universal set U that are not in A

Common Mistakes:  Writing { } = ∅ (correct) but thinking ∅ has one element (no – zero elements)  
Saying two sets are equal when they have same elements but different order (order doesn’t matter)

SUBTOPIC: Algebra of Sets & CardinalityObjective 2: Perform set operations and solve cardinality problemsExplanation (very important formulas):Main Set Operations:Union (A ∪ B) → all elements in A or B or both  
Intersection (A ∩ B) → elements that are in both A and B  
Difference (A – B or A \ B) → elements in A but not in B  
Complement (A′) → elements in U but not in A

Cardinality formulas (very useful):n(A ∪ B) = n(A) + n(B) – n(A ∩ B)  
n(A ∪ B ∪ C) = n(A) + n(B) + n(C) – n(A ∩ B) – n(A ∩ C) – n(B ∩ C) + n(A ∩ B ∩ C)

Answer: 12 + 15 – 5 = 22  
Question 2: "In a class of 50 students, 30 like Mathematics, 25 like English, 10 like both. How many like neither?"
Answer: n(U) – n(M ∪ E) = 50 – (30 + 25 – 10) = 5

Common Mistakes:  Forgetting to subtract the intersection when calculating union  
Adding instead of subtracting in difference

SUBTOPIC: Venn Diagrams and ApplicationsObjective 3: Use Venn diagrams to solve problems involving not more than 3 setsExplanation (step-by-step method):How to solve 2-set and 3-set Venn diagram problems:Draw the Venn diagram (circles for each set)  
Start from the middle (intersection of all sets) – fill smallest part first  
Work outwards – subtract what is already filled  
Fill only one set regions last  
Use the total number (universal set) to find outside regions

In a survey of 100 students:  40 like Football  
35 like Basketball  
30 like Volleyball  
15 like Football and Basketball  
10 like Football and Volleyball  
8 like Basketball and Volleyball  
5 like all three
How many like none?

Step-by-step solution (using Venn diagram):All three = 5  
Football & Basketball only = 15 – 5 = 10  
Football & Volleyball only = 10 – 5 = 5  
Basketball & Volleyball only = 8 – 5 = 3  
Football only = 40 – (10 + 5 + 5) = 20  
Basketball only = 35 – (10 + 3 + 5) = 17  
Volleyball only = 30 – (5 + 3 + 5) = 17  
Total in at least one = 20 + 17 + 17 + 10 + 5 + 3 + 5 = 77  
None = 100 – 77 = 23

Common Mistakes:  Filling from outside instead of inside (always start from the centre)  
Forgetting to subtract the triple intersection from double intersections
