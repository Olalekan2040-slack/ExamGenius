TOPIC: Measures of LocationIntroductionMeasures of location (also called measures of central tendency) summarize a dataset by identifying a single representative value around which the data clusters. The three main measures are mean (average), median (middle value), and mode (most frequent value). These help describe the "typical" or "central" value in data such as exam scores, incomes, heights, or survey results.For a complete beginner:  Mean → add all values and divide by the number of values (the arithmetic average)  
Median → the middle value when data is arranged in order  
Mode → the value that appears most often

This topic is very high-scoring in JAMB Mathematics – usually 4–7 questions every year.
Questions focus on:Calculating mean, mode, and median for ungrouped and grouped data  
Using cumulative frequency tables and ogive (cumulative frequency curve) to find median, quartiles, and percentiles

World-standard learning objectives (aligned with Cambridge IGCSE, WAEC, NECO, IB MYP, and international curricula, expanded for depth):
Candidates should be able to:Calculate the mean for ungrouped data (direct sum ÷ n) and grouped data (using mid-class values × frequency)
Identify the mode for ungrouped data (most frequent value) and grouped data (modal class + estimated mode using formula)
Determine the median for ungrouped data (middle value) and grouped data (using cumulative frequency and ogive)
Construct and interpret cumulative frequency tables and ogive curves
Use an ogive to accurately estimate the median (50th percentile), lower quartile (Q₁ = 25th percentile), upper quartile (Q₃ = 75th percentile), and other percentiles
Apply measures of location to compare datasets and interpret results in real-life contexts (e.g., average score, typical income, middle value in income distribution)

Example Question Pattern (simple to hard – JAMB style):Simple: Find the mean of scores: 5, 7, 8, 5, 9
Answer: Sum = 34, n = 5 → mean = 34/5 = 6.8
Medium: Find the mode and median of: 12, 15, 12, 18, 20, 12, 14
Answer: Mode = 12 (appears 3 times)
Sorted: 12, 12, 12, 14, 15, 18, 20 → Median = 14
Hard: The mean of 8 numbers is 12. If one number is removed, the mean becomes 11. What was the removed number?
Answer: Total = 8 × 12 = 96
New total = 7 × 11 = 77
Removed = 96 – 77 = 19

Common Mistakes:Forgetting to sort data for median  
Using mode when data has no repeated values

SUBTOPIC 2: Mean, Mode, and Median of Grouped Data (Simple Cases)Objective 2: Calculate mean, mode, and median for grouped dataExplanation:Mean (grouped):
Use mid-class value (average of class limits) × frequency
Mean = (sum of mid-class × frequency) ÷ total frequencyMode (grouped):
Modal class = class with highest frequency
Estimated mode = L + [(f_m – f₁)/(2f_m – f₁ – f₂)] × h
Where:  L = lower boundary of modal class  
f_m = frequency of modal class  
f₁ = frequency before modal  
f₂ = frequency after modal  
h = class width

Median (grouped):
Find cumulative frequency → locate median position (n/2)
Median class = class containing n/2
Estimated median = L + [(n/2 – cf_b)/f] × h
(L = lower boundary, cf_b = cumulative frequency before, f = frequency, h = width)Visual Type: grouped frequency table with calculations
Visual Items:  Table with mid-class, frequency, mid × freq, cumulative frequency  
Modal class and median class highlighted

Example Question Pattern:Simple: Find mean from grouped table (simple classes).
(Calculate mid × freq, sum, divide by total freq)
Medium: Identify modal class and estimate mode using formula.
(Apply mode estimation formula)
Hard: From grouped data with total n = 100, find median using cumulative frequency.
(Find class for 50th value, use median formula)

Common Mistakes:Using class limits instead of mid-class values for mean  
Wrong lower boundary in mode/median formula

SUBTOPIC 3: Cumulative Frequency and OgiveObjective 3: Use ogive to find median, quartiles, and percentilesExplanation:Cumulative frequency → running total of frequencies
Ogive → graph of cumulative frequency against upper class boundary  Plotted points: (upper boundary, cumulative frequency)  
Join with smooth curve (S-shape)

Finding values from ogive:Median → 50% of total frequency (n/2) → read x-value  
Lower quartile (Q₁) → 25% of n → read x  
Upper quartile (Q₃) → 75% of n → read x  
Percentile p → (p/100) × n → read x

Visual Type: ogive graph
Visual Items:  Ogive curve with horizontal lines for median, Q₁, Q₃  
Vertical lines showing read-off values

Example Question Pattern:Simple: From cumulative frequency table, find median position.
(n = 80 → median at 40th value)
Medium: Using ogive, estimate the median score.
(Draw horizontal line at n/2, read x-value)
Hard: From ogive, find the 80th percentile.
(80% of total freq → read corresponding score)
Advanced (JAMB common): Given ogive of exam scores (n = 200), estimate interquartile range (Q₃ – Q₁).
(Read Q₁ at 50th, Q₃ at 150th → subtract)

Common Mistakes:Using lower boundary instead of upper for plotting ogive  
Reading wrong frequency level on y-axis
