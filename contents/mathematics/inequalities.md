TOPIC: InequalitiesIntroductionInequalities are mathematical statements that compare two expressions using symbols like <, >, ≤, ≥, or ≠. They are very important in JAMB Mathematics because they test your ability to solve and represent ranges of values, which appear in real-life problems such as budgeting, speed limits, profit margins, and constraints in optimization.For a complete beginner:
Think of inequalities as “less than” or “greater than” situations.
Example: If you have ₦500 and each book costs ₦200, you can buy at most 2 books (x ≤ 2).
This topic is extremely high-scoring in JAMB – usually 3–5 questions every year, often involving linear inequalities, quadratic inequalities with integer roots, and graphical interpretation.World-standard learning objectives (aligned with Cambridge IGCSE, WAEC, NECO, and JAMB focus):
Candidates should be able to:Solve linear inequalities in one variable analytically and represent solutions on number lines
Solve quadratic inequalities (with integral roots only) by factorizing, using sign tables, and identifying solution intervals
Represent solutions of inequalities on number lines and shaded regions on coordinate planes
Interpret and solve real-life problems involving linear and quadratic inequalities
Use graphical methods to solve simultaneous linear inequalities (up to two variables) and identify feasible regions
Understand the effect of multiplying or dividing inequalities by negative numbers (reverse inequality sign)

JAMB Focus:
Most questions are on one-variable linear and quadratic inequalities with integer roots.
Graphical questions usually involve shading regions for two linear inequalities.

Very important: If you multiply or divide by a negative number, reverse the inequality sign!
Example: –2x > 6 → x < –3 (sign flips)

Graphical representation:Use a number line  
Open circle (○) for < or >  
Closed circle (●) for ≤ or ≥  
Shade the direction of the inequality

Key Points:Solve exactly like equations except for negative multiplication/division
Always test one point to confirm shading

Example Question Pattern (simple to hard – JAMB style):Simple: Solve 3x + 5 ≤ 14
Answer: 3x ≤ 9 → x ≤ 3
Medium: Solve –4x + 7 > 15
Answer: –4x > 8 → x < –2 (sign reversed)
Hard: Solve 2(3 – x) ≥ 5x – 8
Answer: 6 – 2x ≥ 5x – 8 → 14 ≥ 7x → x ≤ 2
Advanced (JAMB word problem): A student spends at most ₦1200 on books costing ₦150 each and notebooks costing ₦80 each. If he buys x books and y notebooks, write the inequality and represent on graph (two variables).
Answer: 150x + 80y ≤ 1200 (shade below the line)

Common Mistakes:Forgetting to reverse sign when multiplying/dividing by negative
Using open circle for ≤ or ≥

SUBTOPIC: Quadratic Inequalities (with Integral Roots Only)Objective 2: Solve quadratic inequalities with integral rootsExplanation (the easiest and fastest method for JAMB – Sign Table Method):Steps to solve quadratic inequality (ax² + bx + c > 0, etc.):Factorize the quadratic into (x – p)(x – q) form (roots are always integers in JAMB)
Draw a sign table with critical points (roots) dividing the number line
Test the sign of the quadratic in each interval (+ or –)
Pick the intervals where the sign matches the inequality

Key Points:For > 0 or ≥ 0: choose positive regions  
For < 0 or ≤ 0: choose negative regions  
If ≥ or ≤, include the roots (closed circles)

Visual Type: sign table & number line
Visual Items:  Sign table with roots and intervals  
Number line with shaded solution

Here are perfect visual examples of sign tables:This sign table shows how to solve (x – 2)(x + 3) > 0 (roots –3 and 2).This number line shows the solution shaded for x² – 5x + 6 ≤ 0.This diagram shows a complete 3-step sign table for quadratic inequalities.Example Question Pattern (simple to hard – JAMB style):Simple: Solve x² – 9 > 0
Answer: (x – 3)(x + 3) > 0 → x < –3 or x > 3
Medium: Solve x² – 5x + 6 ≤ 0
Answer: (x – 2)(x – 3) ≤ 0 → 2 ≤ x ≤ 3
Hard: Solve –x² + 6x – 8 ≥ 0
Answer: Multiply by –1 (reverse sign): x² – 6x + 8 ≤ 0 → (x – 2)(x – 4) ≤ 0 → 2 ≤ x ≤ 4
Advanced (JAMB word problem): The profit P (in thousands of naira) from selling x units of a product is given by P = –x² + 20x – 64. For what values of x is the profit non-negative?
Answer: –x² + 20x – 64 ≥ 0 → x² – 20x + 64 ≤ 0 → (x – 4)(x – 16) ≤ 0 → 4 ≤ x ≤ 16

Common Mistakes:Forgetting to reverse inequality when multiplying by –1
Wrong sign in intervals (always test a point in each region)
Excluding roots when inequality is ≥ or ≤

Final High-Level Tips for JAMB Success (World-Class Standard):Always factorize quadratic first – roots are always integers in JAMB  
Use sign table method – fastest and error-proof  
Draw number line with roots and shade correctly  
For word problems: identify inequality direction carefully (e.g., “at least”, “at most”, “non-negative”)
