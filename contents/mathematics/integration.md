TOPIC: IntegrationIntroductionIntegration is the reverse process of differentiation. While differentiation finds the rate of change (gradient) of a function, integration finds the original function (anti-derivative) or the area under a curve.  It is used in real life to calculate:Areas under graphs (e.g., distance from velocity-time graph)
Volumes of revolution
Work done by variable forces
Accumulated quantities (e.g., total cost, total profit)

For a complete beginner:
If dy/dx = 2x (derivative), then y = x² + C (integration – we add constant C because differentiation loses constants).
Integration "undoes" differentiation.This topic is very important in JAMB Mathematics – usually 4–7 questions every year (often combined with differentiation).
JAMB focuses on:Basic indefinite integrals of algebraic and simple trig functions  
Definite integrals (with limits)  
Area under curves (positive areas only)

World-standard learning objectives (aligned with Cambridge IGCSE, WAEC, NECO, IB MYP, and A-Level foundation):
Candidates should be able to:Understand integration as the inverse operation of differentiation
Recognize and apply standard integral forms for algebraic functions (power rule, constants, rational functions)
Integrate basic trigonometric functions (sin x, cos x, sec² x, etc.)
Use integration rules: constant multiple, sum/difference, and linearity
Include the constant of integration (+C) in indefinite integrals
Evaluate definite integrals using limits of integration
Interpret definite integrals as net area under curves (positive above x-axis, negative below)
Solve simple problems involving areas under curves using integration

If dy/dx = f(x), then y = ∫ f(x) dx = F(x) + C
(where F(x) is the anti-derivative, C is constant of integration)Standard Integrals (must memorize):Power Rule:
∫ xⁿ dx = (x^(n+1))/(n+1) + C    (n ≠ –1)Special cases:∫ x⁻¹ dx = ∫ 1/x dx = ln|x| + C  
∫ constant dx = constant × x + C  
∫ 1 dx = x + C

Trigonometric Integrals (JAMB only tests these):∫ sin x dx = –cos x + C  
∫ cos x dx = sin x + C  
∫ sec² x dx = tan x + C

Rules:Constant multiple: ∫ k f(x) dx = k ∫ f(x) dx  
Sum/difference: ∫ [f(x) ± g(x)] dx = ∫ f(x) dx ± ∫ g(x) dx

Example Question Pattern (simple to hard – JAMB style):Simple: Find ∫ (4x³ – 3x² + 5) dx
Answer: 4(x⁴/4) – 3(x³/3) + 5x + C = x⁴ – x³ + 5x + C
Medium: Integrate y = 2x + 3/x + 5√x
Answer: Rewrite: 2x + 3x⁻¹ + 5x^(1/2)
∫ = 2(x²/2) + 3 ln|x| + 5(x^(3/2)/(3/2)) + C
= x² + 3 ln|x| + (10/3)x^(3/2) + C
Hard: Find ∫ (sin x + cos x – sec² x) dx
Answer: –cos x + sin x – tan x + C
Advanced (JAMB definite integral): Evaluate ∫ from 1 to 4 of (3x² – 2x + 1) dx
Answer: [x³ – x² + x] from 1 to 4
= (64 – 16 + 4) – (1 – 1 + 1) = 52 – 1 = 51

Common Mistakes:Forgetting +C in indefinite integrals  
Wrong power when integrating (add 1 to exponent, divide by new exponent)  
Missing negative sign for ∫ sin x dx

Key Tip for JAMB:Always check definite integrals by substituting limits carefully (upper minus lower)

Final High-Level Tips for JAMB Success:Memorize the standard integrals table – write it daily
