TOPIC: Binary OperationsIntroductionA binary operation is a rule that takes two elements from a set and produces one element (still in the same set).
Examples: addition (+), multiplication (×), subtraction (−), division (÷), and custom operations defined by tables (very common in JAMB).For a complete beginner:
Think of a binary operation as a “machine” that takes two inputs and gives one output.
The set could be numbers, letters, symbols, or even people – but the result must stay in the same set.This topic is very important in JAMB Mathematics – usually 3–6 questions every year, mostly involving:Checking if an operation is closed, commutative, associative, or distributive
Finding identity and inverse elements
Using operation tables (Cayley tables) to solve problems

World-standard learning objectives (aligned with Cambridge IGCSE, WAEC, NECO, IB MYP, and international standards):
Candidates should be able to:Define a binary operation on a set and understand closure
Determine whether a given binary operation is closed, commutative, associative, and/or distributive over another operation
Identify the identity element (if it exists) for a given operation
Find the inverse of an element (if it exists) under the operation
Use operation tables (Cayley tables) to solve problems involving binary operations
Solve real-life and abstract problems involving binary operations (e.g., clock arithmetic, modular arithmetic, group-like structures)

For all a, b in the set, a * b is also in the set
(The result stays inside the set)
Commutativity
a * b = b * a for all a, b
(Order does not matter – like addition and multiplication)
Associativity
(a * b) * c = a * (b * c) for all a, b, c
(Grouping does not matter)
Distributivity
a * (b + c) = (a * b) + (a * c)
(One operation distributes over another)

Key Points:Check closure first – if not closed, other properties may not apply
Commutative & associative are independent
Distributivity always needs two operations

Example Question Pattern (simple to hard – JAMB style):Simple: The operation * on set {1, 2, 3} is defined by a * b = ab (ordinary multiplication). Is * closed?
Answer: Yes – all products (1,2,3,4,6,9) but 4,6,9 not in set → No, not closed
Medium: On set of integers, is subtraction commutative? Give reason.
Answer: No – 5 − 3 = 2 but 3 − 5 = –2 (a − b ≠ b − a)
Hard: The operation ⊕ on set {0, 1, 2} is defined by a ⊕ b = remainder when a + b is divided by 3 (mod 3). Check if ⊕ is commutative and associative.
Answer: Commutative – yes (a + b = b + a)
Associative – yes (mod 3 addition is associative)

SUBTOPIC: Identity and Inverse ElementsObjective 2: Solve problems involving identity and inverse elementsExplanation (very important for JAMB):Identity element (e)
An element e such that:
a * e = e * a = a for all a in the setInverse element
For each a, there exists b such that:
a * b = b * a = e (identity)Key Points:Identity is like “0” for addition, “1” for multiplication
Inverse is like “negative” for addition, “reciprocal” for multiplication
Not every set/operation has identity or inverses

Example Question Pattern (simple to hard – JAMB style):Simple: In the set of integers under addition, what is the identity element?
Answer: 0 (because a + 0 = 0 + a = a)
Medium: For multiplication on non-zero real numbers, what is the inverse of 5?
Answer: 1/5 (because 5 × 1/5 = 1)
Hard (JAMB table question): The operation * is defined on set {p, q, r, s} by the table below. Identify the identity element and find the inverse of q if it exists.

(Imagine table shows p * p = p, p * q = q, etc. – identity usually p or e)Advanced: In the set {1, 2, 3, 4, 5, 6} under multiplication modulo 7 (i.e., remainder when product divided by 7), find the identity and inverse of 3.
Answer: Identity = 1
Inverse of 3: find b such that 3 × b ≡ 1 mod 7 → b = 5 (3×5=15≡1 mod 7)

Common Mistakes:Thinking 0 is identity for multiplication (no – 1 is identity)  
Forgetting to check both sides (a * e = e * a = a)

Final High-Level Tips for JAMB Success (World-Class Standard):Always check closure first – many questions stop here  
Memorise the definitions of all four properties + identity + inverse  
Practice reading and interpreting operation tables (Cayley tables) – very common  
For identity: test each element with all others  
For inverse: find element that gives identity when operated with it
